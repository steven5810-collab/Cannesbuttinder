# LTWM Shuffle

Swipe through Cannes Lions award-winning campaigns, 2022–2026.

## Run locally
```
npm install
npm run dev
```

## Deploy to Vercel
1. Push this folder to a GitHub repo (root of the repo, not nested).
2. In Vercel: New Project → import the repo.
3. Framework preset: Vite (should auto-detect).
4. Build command: `npm run build` (default). Output directory: `dist` (default).
5. Deploy.

If Vercel still 404s, check the project's root directory setting matches where package.json lives.
